# SafeX Solutions — Data Science Internship (Day 1 Task)
Intern: Maria Ahmed Track: Data Science

Objective
Set up a data analysis environment and complete a full mini data-analysis cycle — load, clean, analyze, and visualize a real-world dataset.

Dataset
Titanic dataset (loaded via seaborn's built-in dataset loader, based on the well-known Kaggle Titanic dataset).

What's in this notebook
Data loading and exploration (structure, data types, missing values)
Data cleaning (missing age filled with median, missing embarked filled with mode, deck column dropped due to excessive missing values)
2 labeled visualizations:
Survival Count by Passenger Class
Age Distribution of Passengers
Written insight summary based on the cleaned data
Key Insights
1st class passengers had a noticeably higher survival rate than 2nd and 3rd class.
3rd class had the highest passenger count but the lowest survival rate.
Most passengers were young adults, with age distribution peaking between 20-40 years.
Tools Used
Python, pandas, seaborn, matplotlib, Jupyter Notebook

File
SafeX_DataScience_Day1_Task.ipynb — main notebook with code, charts, and insights
